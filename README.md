# Snapwell

Windows 11 用のウィンドウマネージャー（開発中）。

- 画面をグリッド（例: 8×8）で分割し、区画の整数倍でウィンドウを配置・リサイズする
- 隙間なし、または指定ピクセルの間隔（画面端を含む）でウィンドウを整列する
- 投げたウィンドウが、ばね・磁石・壁の物理モデルで四隅や区画に吸い込まれるスナップ
- ホットキーとランチャー、トレイのメニューで操作する
- x64 と ARM64 のネイティブ対応（x86 は非対応）

設計は [docs/DESIGN.md](docs/DESIGN.md) を参照。

ホームページは `site/`（GitHub Pages で公開。`.github/workflows/pages.yml`）。ローカルでは `.claude/launch.json` の `site` で表示できる。
