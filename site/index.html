02 Feel動き

Motion from mass,
not milliseconds.動きは、ミリ秒ではなく
質量から。

Four presets, each a mass, a natural frequency and a damping ratio. Or set your own, along with the magnet's strength. No motion in Snapwell runs on a fixed duration.4 つのプリセットはそれぞれ質量・固有振動数・減衰比の組です。磁石の強さと合わせて、自分で値を決めることもできます。Snapwell の動きに、決まった継続時間はありません。

Each curve is one keyboard move of a single zone from rest, over 1.4 s; the dashed line is the target. A throw uses the same frequency and damping, but it is a different motion. Pick a card to try it in the stage above.曲線は、静止した状態からキー操作で 1 区画動かしたときの位置の変化を表します。横軸は 1.4 秒、破線は目標です。投げるときも同じ固有振動数と減衰比を使いますが、曲線とは別の運動です。カードを選ぶと、上の画面で試せます。

03 What it doesできること

Every window, in its place.どのウィンドウも、あるべき場所へ。

  1. 01

    Zones and corners区画と四隅

    Throw toward a grid zone or a corner. A spring, a magnet and the walls pull the window in.グリッドの区画か画面の四隅へ投げると、ばね・磁石・壁がウィンドウを引き込みます。

  2. 02

    A grid per monitorモニターごとのグリッド

    Each monitor keeps its own grid and its own gap, from 0 to 200 px.モニターごとに、グリッドと間隔（0〜200 px）を別々に設定できます。

  3. 03

    The launcherランチャー

    Ctrl+Alt+Space opens your zones. Drag across any span, or pick halves, quarters, thirds, center or maximize.Ctrl+Alt+Space でランチャーを開き、なぞった範囲にウィンドウを置きます。半分・4 分割・3 分割・中央・最大化のプリセットもあります。

  4. 04

    Arrange整列

    Grid, row, column, or one main window beside a stack. For the current monitor, every monitor, or up to nine windows you pick.グリッド・横一列・縦一列・メインとスタックの 4 方式。対象は現在のモニター、すべてのモニター、または選んだ 9 枚までのウィンドウです。

  5. 05

    Neighbours and monitors隣とモニター

    Snap a window against its neighbour, or send it to another monitor.隣のウィンドウにぴたりと寄せたり、別のモニターへ送ったりできます。

  6. 06

    Your keys, your rulesキーもルールも自分で

    Every hotkey can be changed, and rules can be set for individual apps.ホットキーはすべて変えられます。アプリごとのルールも作れます。

  7. 07

    Windows' snapping, replaced if you like標準のスナップの置き換え

    Optionally take over the built-in snapping. The settings it changes for this are put back.Windows 標準のスナップを置き換えることもできます。そのために変えた設定は元に戻します。

  8. 08

    Settings that travel持ち運べる設定

    A first-run tour, import and export, sync through a folder you choose, Japanese and English, and an option to reduce motion.初回のツアーがあり、設定の書き出しと取り込み、選んだフォルダーでの同期ができます。日本語と英語に対応し、動きを減らすこともできます。

05 Built quietly静かなつくり

Nothing hidden underneath.見えないところも、隠しません。

  • Native x64 and ARM64x64 と ARM64 のネイティブ

    Two native builds. No x86 build, and nothing runs through emulation.2 つのネイティブ版だけを出しています。x86 版はなく、エミュレーションでは動かしません。

  • No DLL injectionDLL を注入しない

    Only documented out-of-process and low-level hooks. It never loads code into another program.文書化されたプロセス外のフックと低レベルフックだけを使い、ほかのプログラムにコードを読み込ませません。

  • No analytics, no tracking解析も追跡もしない

    The update check is off until you turn it on. Sync is a file in a folder you pick.更新の確認はオンにするまで動きません。同期は選んだフォルダーにファイルを置くだけです。

  • Settings put back設定は元に戻す

    If you let it replace Windows' snapping, every setting it changed is put back when you switch it off, quit, or start again after a crash.標準のスナップの置き換えを選んだ場合、変えた設定は、機能を切ったとき・終了したとき・異常終了後の起動時に元に戻します。

06 Questions質問

Before you download.ダウンロードの前に。

Which Windows does it run on?どの Windows で動きますか？

Windows 11, as native builds for x64 and for ARM64. There is no x86 build.Windows 11 です。x64 と ARM64 のネイティブ版があります。x86 版はありません。

Will SmartScreen warn me?SmartScreen の警告は出ますか？

For now, yes. The builds are not code-signed yet. Choose More info, then Run anyway; once you have chosen to trust it yourself, the warning no longer appears. Check the SHA-256 file beside each zip if you want to verify the download.今は出ます。まだコード署名をしていないためです。「詳細情報」を選んでから「実行」を選んでください。自分で信頼して実行すれば、そのあとは警告が出ません。ダウンロードしたファイルを確かめたいときは、zip と同じ場所にある SHA-256 のファイルを使ってください。

Does it send anything anywhere?どこかへ何かを送りますか？

No analytics and no tracking. The only exception is updating. The update check is off until you turn it on, and the signed download from GitHub happens only when you choose Update and restart. Settings sync is only a file in a folder you pick, such as one that OneDrive or Dropbox already syncs.解析も追跡もしません。例外は更新だけです。更新の確認はオンにするまで動きません。「更新して再起動」を押したときだけ、署名つきの配布ファイルを GitHub からダウンロードします。設定の同期は、OneDrive や Dropbox などで同期しているフォルダーにファイルを置くだけです。

Does it inject code into my apps?アプリにコードを注入しますか？

No. Snapwell uses out-of-process event hooks and the low-level keyboard and mouse hooks, the documented ones. It never loads a DLL into another program.しません。文書化されたプロセス外のイベントフックと、キーボード・マウスの低レベルフックだけを使います。ほかのプログラムに DLL を読み込ませることはありません。

Does it change Windows settings?Windows の設定を変えますか？

Only if you ask it to replace Windows' own snapping. It remembers the original values and puts them back when you switch it off, quit, or start again after a crash. Starting with Windows is also off until you turn it on.標準のスナップの置き換えを選んだ場合だけです。元の値を覚えておき、機能を切ったとき・終了したとき・異常終了後の起動時に元に戻します。Windows と一緒に起動する設定も、オンにするまでは無効です。

Can I change how windows move?動き方は変えられますか？

Yes. Pick Standard, Crisp, Smooth or Bouncy, or set mass, natural frequency, damping ratio and magnet strength yourself. The page above uses the same model.変えられます。標準・きびきび・なめらか・はずむから選ぶか、質量・固有振動数・減衰比・磁石の強さを自分で決めてください。このページのデモも同じモデルです。

Where do I set it up?どこで設定しますか？

The tray icon opens a settings window with a short first-run tour. Everything can be changed there, hotkeys included.トレイのアイコンから設定画面を開きます。初回は短いツアーがあります。ホットキーも含めて、すべてそこで変えられます。
