What Snapwell does

Throw a window, it snaps to a zone.

It reads the speed you let go with, works out where the window would coast, and carries it into the nearest zone.

Gaps stay even, edges included.

Windows sit flush or apart by the gap you choose, and zone widths never differ by more than one pixel.

One key arranges every window.

Grid, row, column, or one main window beside a stack. Ctrl+Alt+A tidies the current monitor.

Drag across a grid to place.

The launcher shows your zones. Sweep over any span of them and the window takes exactly that area.

Native on x64 and ARM64.

No DLL injection and no network access. Snapwell uses documented Windows hooks and nothing else.

Tune the feel

Choose how a window moves: light or heavy, loose or magnetic. Every motion comes from mass, stiffness and damping, never from a duration.

How a throw works

Grab the title bar.

Hold any window by its title bar and move it. Snapwell watches how fast you are going when you let go.

Let go.

From that speed it works out where the window would coast to, and picks the nearest zone. A dotted line shows the plan.

It settles in.

A spring pulls the window in, a magnet takes the last few pixels, and walls catch a throw that is too hard.

Questions

Which Windows does it run on?

Windows 11, as native builds for x64 and for ARM64. There is no x86 build, and nothing runs through emulation.

Will SmartScreen warn me?

Yes, for now. The v1.0.0 builds are not code-signed, so Windows may say it protected your PC. Choose More info, then Run anyway. A SHA-256 checksum file sits beside each zip so you can check the download first.

Does it send anything anywhere?

No. There is no telemetry, no account and no update check. Settings sync is only a file in a folder you pick, such as one that OneDrive or Dropbox already syncs.

Does it inject code into my apps?

No. Snapwell uses out-of-process event hooks and the low-level keyboard and mouse hooks, the documented ones. It never loads a DLL into another program or touches another process's memory.

Does it change Windows settings?

Only if you ask it to replace Windows' own snapping. It then remembers the original value and puts it back when you switch it off, quit, or start again after a crash. Starting with Windows is also off until you turn it on.

Can I change how windows move?

Yes. Pick one of four presets, or set mass, natural frequency, damping ratio and magnet strength yourself. The page above uses the same model.

Where do I set it up?

The tray icon opens a settings window with a short first-run setup. Everything can be changed there, hotkeys included, without editing a file.

Get Snapwell 1.0.0

A portable zip: unpack it anywhere and run Snapwell.exe. Pick the build that matches your PC.
