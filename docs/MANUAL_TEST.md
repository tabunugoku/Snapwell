# 実機で確かめること

自動テストはすべて偽の Win32 API で動く。ここに挙げる点は、実機で手で確かめる。確かめたら `[x]` にし、日付と環境 (x64 / ARM64、DPI、モニター構成) を書く。

OS の設定を変える項目 (「設定を変える」と書いたもの) は、ユーザーの同意を得てから行い、終わったら元に戻す。
