# 実機で確かめること

自動テストはすべて偽の Win32 API で動く。ここに挙げる点は、実機で手で確かめる。確かめたら `[x]` にし、日付と環境 (x64 / ARM64、DPI、モニター構成) を書く。

OS の設定を変える項目 (「設定を変える」と書いたもの) は、ユーザーの同意を得てから行い、終わったら元に戻す。

## 操作感の「磁石の強さ」と「吸着半径」と feel の物理（すべて実機未確認）

- [ ] 設定画面の「操作感」で磁石の強さ（0〜2）と吸着半径（8〜96）を変えて保存でき、再起動後も保たれる。範囲外の入力は既定値に戻る。操作感のカードを選び直すと、磁石の強さは語から決まる値（airy 0.5、他は 0.6）に戻る。
- [ ] 惰性で止まる距離が旧版より短い（airy で 0.22 → 約 0.066 秒分の速度）。同じ位置へ吸着させるには、旧版より速く投げる必要がある。投げる強さの感覚が許容できる。
- [ ] 四隅モード：四隅のどれに止まるかが、投げた方向と速さで自然に決まる。表示される枠（プレビュー）と実際に止まる角が一致する。
- [ ] 磁石の強さを 0 と 2 にして投げると、2 のほうが吸着直前に強く引き込まれる（半径の内側）。
- [ ] 吸着半径を 8 と 96 にすると、96 のほうが遠くから引き込まれる。隣の辺への吸着距離（24 論理 px）は半径で変わらない。
- [ ] 拡大率 150% のモニターで、半径が論理距離どおりに効く。
- [ ] 非常に速く画面端へ投げたとき、壁を数 px 越えてから戻っても、止まった位置が作業領域の中に収まる。
- [ ] 区画の判定の途中で壁にぶつかっても、プレビューと最終位置が一致する。
- [ ] 「動きを減らす」がオンのとき、停止点へ即座に移動する。
- [ ] 四隅モードの予測（最大 6 秒、1/60 秒刻み）が、ドラッグ中のプレビュー更新でカーソルの動きを妨げない（引っかからない）。
- [ ] 区画モード：左の半分から右の半分へ投げるとき、旧版より強く投げないと反対側に届かない（磁石場が手前の停止点へ引き戻すため）。普段の投げ方で届くか、届かなすぎないか。
- [ ] 区画モード：弱く投げたとき元の側の半分に戻り、強く投げたとき反対側の半分に止まる。プレビューの枠と実際に止まる区画が一致する。
- [ ] 区画モード：最大化（上中央への投げ）と隣の辺への吸着は、勢いに関係なく従来どおり。上端・下端に押し付けたカーソルの四分割も従来どおり。

## 操作感の 5 つの値の自由編集と「カスタム」（すべて実機未確認）

- [ ] 設定画面の「操作感」で、質量（0.15〜8）・固有振動数（0.4〜7 Hz）・減衰比（0.1〜1.6）・磁石の強さ（0〜2）・吸着半径（8〜96）をスライダーと数値入力の両方で変えられる。範囲外を入力すると範囲の端に収まる。
- [ ] プリセット（airy・snappy・heavy・bouncy）のカードを押すと、5 つの値（吸着半径は据え置き）がそのカードの値になり、カードが強調される。値を一つ変えると表示が「カスタム（○○ から変更）」になり、どのカードも強調されない。「プリセットに戻す」または同じカードをもう一度押すと元の値に戻る。
- [ ] 値を保存して設定画面を開き直すと、カスタムの値と表示が保たれる。起動中の Snapwell に反映され、投げた動き（振動数・減衰比・磁石の強さ・半径）が変わる。**質量は吸着の動きを変えない**（feel の磁石場は力が質量に比例するため。k と c の表示だけが変わる）ことを承知のうえで、操作の意味が通るか。
- [ ] 旧い設定ファイル（質量・振動数・減衰比がない）を開くと、プリセットのまま読み込まれ、読み取り専用にならない。
- [ ] 設定のエクスポートとインポートで、カスタムの値が受け渡せる。インポートの差分に「カスタム（○○ から。質量 …）」と出る。
- [ ] 「試す」領域でタイトルバー（上の 30 px の帯）をつかんで投げると、いまの 5 つの値で動く。止まる先は本体と同じ規則（SnapResolver）で決まる: 区画では、左右に投げると半分、上端寄りと下端寄りで四分割、中央から上へ強く投げる（予測点が上端の外）と最大化、横に寄った位置から上へ投げると最大化にならず上の四分割。四隅では投げた角。値を変えるとすぐ動きが変わる。150 px/s 未満で離すと吸着せずその場に置かれる。「動きを減らす」がオンなら、アニメーションせずに止まる先へ移る。矢印キーでも投げられる。
- [ ] 試す領域は、タイトルバーをつかんだときだけ動く（実際のウィンドウと同じ）。タイトルバーより下の本体を押して引いても動かず、飛んでいる最中の本体を押しても止まらない。マウスはタイトルバーの上でつかむ形のカーソル（モックアップのみ。実アプリは未実装）。タッチとペンは、タイトルバーの四方 8 px の外までつかめる（本体の奥は含まない）。区画の大きさに止まったウィンドウのタイトルバーをつかむと元の大きさ（132×88）に戻り、つかんだ点はタイトルバーの上に残る。タイトルバーは実物より大きめ（高さ 30 px、全体 88 px）。
- [ ] 試す領域の動きと、実際のウィンドウを投げたときの動きが、同じ値で近い感触になる（試す領域は舞台の px、本体は物理ピクセルのため、吸着半径の効き方は同じ値でも見かけの大きさが違う）。
## トレイメニューの待機カーソル（すべて実機未確認）

- [ ] トレイを右クリックしてメニューを開いている間、メニュー上・外・項目の上でカーソルが矢印のままで、待機カーソルにならない。ARM64・x64、ライト・ダーク、拡大率 100%・150%・200% の各組み合わせで確かめる。
- [ ] メニューを閉じた後もカーソルが矢印のまま戻る。
- [ ] 直らなかった場合は、メニューを開いた直後・項目ホバー中・選択後のどの時点で待機カーソルが出るかを控え、`%LOCALAPPDATA%\Snapwell` のログの末尾を保存する。原因は推測であり、WM_SETCURSOR 以外の原因が残る可能性がある。
