# ランチャーのオーバーレイ レビュー: Codex 向けの数値仕様

`overlay-review.html` の JSON から生成。単位は論理 px、物理 px は × 拡大率の四捨五入。色は RGBA。

## 判断してほしい点

- **D1. ライトの選択セルを透ける塗りにするか** 推奨: 透ける塗りに統一 (推奨)。いまのライトは不透明な水色で、選択した区画の下の画面が見えない。ダークと同じ 28% の青 (alpha 71)にすると、置く先の画面を見ながら選べる。見た目が変わる点なので確認したい。
- **D2. 角を 8 にそろえるか** 推奨: そろえる (推奨)。セル 4 → 8、ラベル 6 → 8。ドラッグのプレビュー (8) と同じ角になる。小さいセル (12×6 分割の低い画面) でも半径 8 は収まる。
- **D3. 実装の順序** 推奨: ランチャーの PR のマージ後 (推奨)。選択ラベルの寸法は LauncherPanelLayout.cs (WithSelection) にあり、いま Codex がそのファイルを編集中。重ねると衝突するので、codex/launcher-polish を main に入れてから worktree を切る。
- **D4. ドラッグのプレビュー (Preview) の扱い** 推奨: 次の画面として別にレビュー (推奨)。BlueBackground・BlueLine・角 8 を共有している。Z3 の新トークンに合わせるかは、プレビューのレビューで決める。今回は触らない。

## 受け入れ条件

- ZoneSelected が OverlayPalette に増え、ライトとダークで (31,108,159,71)。BlueBackground の値は変わらない (パネルのタグ・行・役割の面が変わらない)。
- PaintLauncher の選択セルの中央の画素が、ZoneSelected を暗幕とセルの上に重ねた結果になる。ライトでも下の暗幕・壁が透ける (不透明でない)。
- セルの角の画素 (0,0) が、拡大率 1.0 でセルの塗りに覆われない (角 8)。拡大率 1.25・1.5・2.0 で、角の半径が 8 × 拡大率に追従する。
- CellBorder が、ライト (0,0,0,36)、ダーク (255,255,255,36)。合成後の面と枠の輝度比が、ライト・ダークとも 1.3 以上 (本ページの表で確認)。
- カーソルの枠が 2 px の BlueText のまま、角が 7 (セル 8 − inset 1)。
- 拡大率 1.0 で、選択ラベルの高さが 32、幅が測定した文字幅 + 24。左右対称で、画面端では作業領域内に収まる (既存の Clamp を保つ)。
- 選択ラベルの角が 8、枠が BorderStrong。
- showZoneLines = false で、選択セルを含むすべての枠が描かれない (既存の動作)。
- 既存の動作 (ヒットテスト、選択範囲、Cursor の移動、PanelBuildCount などの再利用、alpha 零の領域を作らない暗幕) が変わらない。既存テストの期待値は、本表の数値に追従させる。
