# ドラッグ中のプレビュー レビュー: Codex 向けの数値仕様

`preview-review.html` の JSON から生成。単位は論理 px、物理 px は × 拡大率の四捨五入。色は RGBA。

## 判断してほしい点

- **D1. 枠を内側に描くか (V4)** 推奨: 内側 (推奨)。置き先の矩形より外へ出ないので、間隔 0 の隣の区画へ重ならない。見た目は 2 px 太るぶん内側が 1 px 狭くなるだけ。いまの「縁の中心」を保つなら V4 を外す。
- **D2. 予測線 (V7, V8) も同時にそろえるか** 推奨: そろえる (推奨)。既定で無効の機能 (ShowPredictionLine = false) だが、同じ画面の破線なので同時に直す。差分は PredictionLine の二行。
- **D3. 枠をアクセント (BlueText) の実線の濃さにするか** 推奨: BlueText (推奨)。BlueLine (alpha 140) のままだと壁に対し 2.3 : 1。濃くすると「置き先」が強く見えすぎるなら、alpha 200 程度の中間もある。数値で指定したいときはお知らせください。

## 受け入れ条件

- ライトの Preview の塗りが、ZoneSelected (31,108,159,71) を壁へ重ねた結果になる。不透明でない (中央の画素の alpha が 255 未満)。ダークの塗りは変わらない。
- 枠の色が BlueText (ライト・ダークとも alpha 255 の画素が出る)。BlueLine の値は変わらない。
- 拡大率 1.0 で枠が 2 px、1.25・1.5・2.0 で round(2 × 拡大率) px の整数。端数の半透明の画素が太さ方向に出ない。
- 枠の画素が、target の矩形の外へ出ない (矩形の外側の画素が alpha 零)。
- 枠の破線が、周囲長 12 論理 px の周期で 6 描き 6 空け。角でも切れ目が連続する。
- 予測線の太さが枠と同じ整数 px、破線が周期 12 で 6 / 6。終点の点と色は変わらない。
- showZoneLines = false では枠が描かれず、塗りと (有効なら) 予測線だけが出る。
- 既存の動作 (Local での切り詰め、負の座標のモニター、作業領域の外へ出る target、alpha 零の領域の入力透過) が変わらない。既存テストの期待値は、本表の数値に追従させる。
