トレイ UI レビュー

通知領域のアイコンから開くメニュー（src/Snapwell.App/Tray/Menu）と、トレイのアイコン。現状は実装の値（TrayMenuLayout・TrayMenuRenderer・OverlayPalette）をそのまま写しています。実機の画面ではなく、寸法と色の再現です。影だけは実装の近似です。見本の座標は 1 論理 px = 1 CSS px です。

判定

軽い トレイのメニューは、もともと静かで、この製品だけのものです（物理モーションのスイッチ、製品の印が状態で形を変えるアイコン）。装飾の削除ではなく、寸法の整列・コントラスト・状態の見せ方を直す磨き込みにします。画面の作りと機能は変えません。

方向

製品
Windows 11 の通知領域から、有効・一時停止、整列、ランチャー、設定、終了を選ぶ小さなメニュー。
性格
静か、正確、軽い。
世界
タスクバーと OS の面。メニューの面は無彩色の段で、色はアクセントと状態の点にだけ使う。
見せ場
ヘッダーの物理モーションのスイッチと、製品の印。ほかは色も効果も足さない。
署名
状態を「点」で示す。トレイのアイコンの右上の図形（四角・中空・丸）と同じ文法を、メニューでは 6 px の点にする。

判断をお願いしたい点

  1. Q1 状態タグ（緑・黄・赤の塗りの丸薬）を、点＋文字にする。 推奨。通常の「有効」まで色の塗りで目立たせず、文字は残す（TrayIconPolicy の「色だけに頼らず状態を文字でも伝える」の意図は守る）。残す案は、丸薬のまま寸法だけそろえる。
  2. Q2 ラベルの前の 34 px の空きを詰める。 推奨。プロファイル用のチェック欄の名残で、いまは何も入っていない。代わりに線のアイコンを入れる案もあるが、描画の部品とテストが増える。
  3. Q3 ランチャーの行にホットキーを薄く添える（例 Ctrl+Alt+Space）。この見本と仕様には含めていない。設定値をメニューに渡す配線が要るため、やるなら別の項目にする。
