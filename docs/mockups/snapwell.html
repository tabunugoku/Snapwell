Windows の標準機能

Snapwell が有効な間だけ、Windows の標準の配置機能を止めたり、Snapwell の操作に置き換えたりします。各項目の下に、Windows では何が起きるか・Snapwell ではどうなるかを示します。止める前の値を保存しておき、無効にしたとき・終了したとき・異常終了のあとに起動したときに戻します。

標準の枠は出さず、自分の分割案の線が薄く出て、狙う区画だけ青くなります。離すと、ばねと磁石の物理モデルでその区画に収まります。大きさは決まった形に限りません。

止める理由: 標準のスナップと同時に動くと、離した瞬間に 2 つの大きさが競い合うため。設定アプリの「ウィンドウのスナップ」と同じスイッチを切ります。

Windows の標準

ウィンドウの最大化ボタン（□）にポインターを載せると、右下にメニューが開きます。候補は 5 種類（半分ずつ・2 対 1・左と右の上下分け・4 分割など）で、選ぶとウィンドウがその形の区画に収まります。先頭の候補には、開いている別のアプリのアイコンが出ます（そのアプリと並べる提案）。

→
Snapwell が有効な間

最大化ボタンにポインターを載せても、メニューは出ません（ボタンそのものは普通に最大化します）。区画への配置は、ランチャー（Ctrl+Alt+Space）・ホットキー・ドラッグで行います。

止める理由: 標準のメニューの形は Snapwell の分割案と別物で、同じウィンドウに 2 通りの配置先が出てしまうため。Windows の設定（システム → マルチタスク）では「ウィンドウのスナップ」の下位の項目で、上の「ドラッグでのスナップ」を止めると一緒に消えることを実機で確認しました。単独でもオフにできるので、上を止めない場合のために個別のスイッチを持ちます。実装前に検証が要ります（レジストリの値は Windows のビルドで変わります）。

Snapwell が有効な間

上端に候補のバーは出ません。上端へ近づけても何も起きず、区画への吸着は Snapwell のドラッグ（離した先のプレビュー）が受け持ちます。

止める理由: ドラッグ中に標準のバーと Snapwell の区画のプレビューが重なって見えるため。最大化ボタンのメニューと同じく、「ウィンドウのスナップ」を止めると一緒に消え、単独でもオフにできることを実機で確認しました。実装前に検証が要ります（24H2 より前の Windows には無い機能です）。
