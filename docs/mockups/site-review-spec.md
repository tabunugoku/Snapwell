# ホームページ (site/) のレビュー: Codex への数値仕様

`site-review.html` の JSON から生成。単位は CSS px。対象は `site/css/home.css` だけ。`js/`・`index.html`・`assets/`・`video/` は変えない。

## 判断 (推奨はすべて採用の前提)

- **D1. 操作部品の角をアプリ本体にそろえるか (S1)** 推奨: そろえる (推奨)。ボタン・チップ・『動きを減らす』を 8、切り替えの枠を 8、中の項目を 6 (枠 8 − 余白 2)。キー表示 4 は変えない。高さ 28・文字 13 は製品と同じなので変えない。 代わり: 6 のまま。サイトだけが古い製品の見た目になる。
- **D2. 明るい面の補助文字を 4.5:1 にするか (S2)** 推奨: する (推奨)。`--muted` 明を #787774 → #6B6A67 (アプリ本体と同じ。白の上で 5.41:1)、`--accent` 明を #1F6C9F → #1B6292 (水色の薄い面の上で 5.16:1)。暗は変えない。 代わり: 変えない。水色が少し明るいまま。
- **D3. 文字の段に外れた値をそろえるか (S3)** 推奨: そろえる (推奨)。12.5 → 13、15.5 → 16、15 → 16、19 → 18、17 → 16。『隠しません』の説明 (15 → 16) は、列の幅が狭いので 1 行増えることがある。 代わり: 15 → 14 にして行数を保つ (説明の字が小さくなる)。
- **D4. 偽の太字を止めるか (S4)** 推奨: 止める (推奨)。`@font-face` に `font-weight: 500 600` を宣言し、合成させない (500 の線で描かれる)。 代わり: そのまま。英字だけ太くなる。
- **D5. フッターのリンクを押しやすくするか (S5)** 推奨: する (推奨)。押せる高さを 32 にし、行の間の 8 を 0 にして見た目の間隔は保つ。『Replay intro』も 32。 代わり: 変えない。
- **D6. 英語だけの紹介の映像を今回直すか (S6)** 推奨: 直さない (推奨)。日本語の映像は作り直しなので別の作業にする。ページには『画面のモックアップ』と書いてある。 代わり: 日本語ページでは映像の前に注記を足す。

## 監査

- **S1 (P1) 操作部品の角が 6 で、アプリ本体の 8 とずれている** サイトのボタン・言語と配色の切り替え・プリセットのチップは、『製品と同じ値』として角 6 (切り替えの中の項目は 4) で作られている。製品はその後、操作部品を角 8 にそろえた (設定画面 PR 154、ダイアログ PR 155)。サイトの断片は古い値のまま。 (home.css の `--btn-r`、`.lang/.theme/.seg`、`.motion-btn`)
- **S2 (P1) 明るい面の補助文字が 4.5:1 に届かない** 『動きを減らす』(押した状態、13 px) は水色の文字が水色の薄い面に載って 4.47:1。製品の断片のウィンドウ名 (12 px) は #787774 で 4.25:1。製品の補助文字は #6B6A67 にそろえてあり、サイトの断片だけ古い灰色。 (`--accent` 明、`--muted` 明)
- **S3 (P2) 文字の大きさが段から外れたものがある** 12.5 (切り替え)、15.5 (行の説明)、15 (『隠しません』の説明)、19 (FAQ の質問)、17 (スマホの質問) は、製品の段 (11 / 12 / 13 / 14 / 16 / 18) にない。同じ『説明の段落』が 15.5 と 15 に分かれている。
- **S4 (P2) 日本語の見出しの英字が偽の太字** 日本語の見出しは太さ 600 を指定するが、Newsreader は 500 の 1 ファイルだけ。『Snapwell 1.0.4 を』のような英字の部分が、ブラウザーの合成の太字になり、線がつぶれて見える。 (`@font-face`)
- **S5 (P2) フッターのリンクの押せる高さが 22** GitHub・Issues・MIT ライセンス・サードパーティーの 4 つは、押せる高さが 22 で、24 (WCAG 2.5.8) を下回る。タッチでも広がらない。 (`.foot-links a`)
- **S6 (P3) 紹介の映像が英語だけ** 『投げる様子を、見る。』の映像の中の文字 (Throw a window. ほか) は英語のみで、日本語のページでも英語のまま。映像は録画ではなく画面のモックアップである旨が、すぐ下に書いてある。作り直しが要るので、今回は直さない (判断 D6)。

## 受け入れ条件

- `site/css/home.css` だけが変わる (`js/`・`index.html`・`assets/`・`video/` は変えない)。
- `getComputedStyle` で、`.btn` の角が 8、`.lang` の角が 8 と中の項目が 6、`.motion-btn` が 8、高さは 28 のまま。
- 明の本文サイズの文字 (ヒーローの大見出しの薄い行と、製品の断片の飾りを除く) が、すべて 4.5:1 以上。『動きを減らす』と製品のウィンドウ名を確かめる。
- ページ中のテキストの `font-size` の種類から、12.5・15・15.5・19・17 が消える。
- `@font-face` が `500 600` で、日本語の見出しの英字が合成の太字にならない (目で見て、線がつぶれていない)。
- フッターのリンクの高さが 32 以上、375 px 幅で横にはみ出さない。
- ライト・ダーク × 日本語・英語の 4 通りで、ヒーロー・操作感・できること・ダウンロード・フッターを目で確かめ、文字が欠けない・重ならない。確かめたら、スクリーンショットは Git に入れない。
- `site/**` を main に入れると GitHub Pages が自動で公開される。マージの前に、利用者が見た目を確かめる。
