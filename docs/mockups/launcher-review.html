ランチャー UI レビュー

対象は、ホットキーで開くランチャー (区画のパネル + ウィンドウ一覧)。トレイメニューのレビュー (PR 148) で決めたトークン (4 の倍数の格子、文字 12 / 13、補助文字のコントラスト 4.5 以上、Hover、2 px の焦点枠) を、ランチャーにも適用する案。as is は LauncherPanelLayout と LauncherWindowListLayout の式から再現した。実描画との差は、実装後に GDI で書き出して確かめる。

1. as is / to be (明 / 暗)

拡大率 1.0 の論理 px。寸法線は橙の破線 (左上の数字が x,y と 幅×高さ)。as is の端数 (27.2 / 29.2 / 18.8 / 19.2) は式のとおりで、表示は 0.1 px まで丸めている。to be はプリセットのボタン幅が +8 (アイコンとラベルの余白) なので、1 行に入る個数が減り、この見本 (6 個・日本語) では 2 行に折り返してパネルが 180 になる。折り返しは文言と選んだプリセットの数に依存する (as is も個数が増えれば折り返す)。
