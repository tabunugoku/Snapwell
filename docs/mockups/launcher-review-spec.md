# ランチャー UI レビュー: Codex 向けの数値仕様

`launcher-review.html` の JSON から生成。単位は論理 px、物理 px は × 拡大率の四捨五入。座標はパネルの左上が原点 (一覧は x を同じ、y をパネルの下端から)。

## 判断してほしい点

- **D1. 行・ボタンの密度は 32 (トレイと統一) にするか、いまの 28 を保つか** 推奨: 32 (推奨)。32 でパネルが 124 → 140、一覧 5 件が 356 → 388 になる。28 にすると 132 / 364 程度に収まるが、トレイ・設定画面の行 32 とそろわない。低い画面ではコンパクトが効く。
- **D2. ホバー状態 (H1) を今回に含めるか** 推奨: 別の PR にする (推奨)。LauncherController にポインタの位置の状態を持たせ、再描画の鍵に入れる変更が要る。寸法・色・焦点枠とは性質が違うので分ける。含める場合も仕様は H1 のとおり。
- **D3. ▾ ▸ ✓ の図形化 (F6) を今回に含めるか** 推奨: 含める (推奨、別コミット)。役割の ◉/○ は図形化済みで、同じ方式 (整数ピクセルの矩形・線) で描く。回帰の範囲は一覧の見出しと行だけ。
- **D4. 着手の順序** 推奨: PR 148 のマージ後に実装。Muted の変更 (#6B6A67) と Hover は PR 148 で入る。ランチャーはそれに依存するので、PR 148 を main に入れてから worktree を切る。

## 受け入れ条件

- 拡大率 1.0 で、パネルと一覧のすべての矩形 (行・ボタン・キー面・ピル) の x・y・幅・高さが、文字の幅に依存するもの (プリセットの幅・キーの幅・タグの幅) とアイコンの内部を除き 4 の倍数。
- パネルの内容の左端 x16 と一覧の内容の左端 x16 が一致する。
- 拡大率 1.0 で、パネル (プリセット 1 行・キー 1 行) の高さが 140、折りたたみの一覧が 48、展開 (窓 1 / 3 / 5 件) が 244 / 316 / 388。
- 文字の大きさは 12 と 13 だけ (タグ 12・600、見出しと対象名 13)。10.5 / 11.5 / 12.5 が残らない。
- ライトの Muted と Surface / Surface2 / Hover のコントラストが 4.5 以上。ダークも 4.5 以上。
- Focused の行が、選択の有無にかかわらず 2 px の BlueText の枠で描かれる。選択中で焦点なしの行は枠 1。
- ▾ ▸ ✓ が図形で、フォントなしでも同じ形になる (描画結果が言語・フォントに依存しない)。
- 拡大率 1.25・1.5・2.0 で、行・ボタンの丸めの誤差が 1 px を超えない。
- スクロールバーの幅が行高に依存しない (12)。
- 既存の動作 (ヒットテスト、ページ送り、選択上限、コンパクトへの縮小、ドラッグ中の再配置) が変わらない。LauncherPanelLayoutTests など既存のテストの値は更新してよいが、判断ではなく数値に追従させる。
- 判断 D2 を採るとき: ホバー中の項目が変わったときだけ再描画される (全レイヤーを毎回作り直さない)。
